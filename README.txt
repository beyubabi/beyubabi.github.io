Bayode website update

Upload these website files to the root of the GitHub Pages repository:

- styles.css

The Open Graph image URL is https://beyubabi.github.io/og-image.jpg.

The site includes linked currency pickers in the Services section and estimator. Prices convert from USD to GBP, NGN or GHS using rates from open.er-api.com. The selected exchange rate and update date are shown beside both pickers. Currency selection is guessed from browser language/time zone and can be manually changed. Rates are approximate and the final project price is confirmed in writing; if rates are unavailable, the site remains in USD.

Mobile improvements include a labeled floating Home/Services/Work/Contact bar, two-column service and portfolio cards, full-fit portfolio images, theme icons, and a floating back-to-top arrow.

Extract this ZIP and upload/replace the four site files at the root of the GitHub Pages repository, then commit/push the changes. No changes have been published to GitHub automatically.
