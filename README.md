# Bayode — three-offer portfolio update

This is the complete static website based on `beyubabi/beyubabi.github.io`. It retains the approved dark-slate, emerald-green and cobalt-blue identity, improved typography, accepted header, project content, FAQs and matching dark/light portrait banners. The original live GitHub Pages site has not been changed by this package.

## The three primary offers

| Offer | Published pricing | Quote behavior |
| --- | --- | --- |
| Shopify Store Build | Custom quote | Collects product count, project brief and preferred launch timing; no made-up fixed price |
| Shopify Migration | From $650 | Existing catalogue-volume and selected add-on estimate rules are retained |
| Storefront Improvement Sprint | From $350 | Existing catalogue-review and selected add-on estimate rules are retained |

Migration remains the featured specialist offer. Each card's action selects its matching quote option. The $120 Store Audit remains available in a smaller secondary panel, not as a fourth primary card. The provisional fees in the private income plan are **not** published as confirmed store-build or care prices.

Estimates are indicative, not binding quotes. Final scope, timing, third-party charges and payment currency are agreed before work starts. The former fixed 1,400 NGN/USD conversion is no longer represented as a current quote; naira invoicing is agreed when quoted. New builds do not inherit migration platform fields or hidden add-on charges. Prepared WhatsApp links are inquiries only; the website does not automatically send messages or take payment.

Service descriptions and search/social metadata now include full store builds, migrations and storefront improvements. They do not promise guaranteed sales, unchanged SEO traffic or unrestricted checkout customization. Existing client testimonials and case-study metrics remain supplied portfolio content, not independently audited results.

## Upload to GitHub Pages

Extract the ZIP. Upload the **extracted contents**, not the ZIP itself, into the publishing root of `beyubabi/beyubabi.github.io`. Do not create an extra enclosing folder. Back up the current site and preserve unrelated files, including any custom-domain file and deployment workflow.

Keep `index.html`, `styles.css`, `brand.css`, `app.js`, `og-image.jpg`, `og-image-light.jpg`, `favicon.svg` and all project images together. Prefer a branch/pull request for review, then merge when ready to publish. If the existing Pages deployment already works, keep its configuration. For a simple branch-based deployment, use **Settings → Pages → Deploy from a branch → main → /(root)**. This package has no backend or build dependencies.

## Preserved design and interactions

The mobile work section displays two cards per row up to 768px, with six cards in three rows and genuinely shorter mobile copy. Desktop retains three columns and original descriptions. Filtering can display one matching card without placeholders. All six FAQs remain, including complete Shopify builds and WordPress/WooCommerce work; answers are not clipped on narrow screens.

The site's Light/Dark/System controls select `og-image-light.jpg` or `og-image.jpg`, including the mobile toggle and saved preference. Both are 1200 × 630; the dark banner remains the social-sharing image. The palette is dark `#090D16` / emerald `#10B981` / cobalt `#3B82F6`, with light-mode emerald `#047857` for readable controls. Fonts are Barlow Condensed, Plus Jakarta Sans and JetBrains Mono with system fallbacks.

Open Graph and Twitter use the existing public matching dark-banner URL. After deployment, you may change both image URLs to `https://beyubabi.github.io/og-image.jpg`. Canonical stays `https://beyubabi.github.io/`.

## Run locally

From this folder run `python3 -m http.server 3000`, then visit `http://localhost:3000/`. Google Fonts, external store links and YouTube content require internet access.

The three-offer controls and custom quote were checked at 320, 375, 430, 768 and 1280px. Focused checks cover correct card selection, brief/timing/count in the prepared WhatsApp message, no fabricated build price, migration/sprint surcharge and add-on arithmetic, and preserved mobile work/theme behavior. No JavaScript page errors were observed. A local preview or download package is not proof of GitHub publication; write access to the user's GitHub repository remains a separate authorization blocker.
